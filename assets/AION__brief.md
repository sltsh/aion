# Aion product brief

## Product

Aion is an SLT product: a dark theme and color system for editors, terminals,
and web interfaces.

It provides one coordinated palette across those surfaces. Its implementation
computes colors from authored tokens, verifies contrast and renderer states, and
emits the formats used by each supported application.

## Name and conceptual origin

The name comes from the Ancient Greek `aion`: an age, an epoch, or a span of
existence.

Useful conceptual themes include:

- continuity across different tools and surfaces;
- durable structure over time;
- a coherent system rather than isolated colors;
- precision, measurement, and controlled relationships;
- familiar syntax roles carried by a distinct interface identity.

Interpret these themes structurally and abstractly. Time-related work should not
default to clocks, hourglasses, infinity symbols, rings, or other literal time
metaphors.

## Relationship to SLT

Aion inherits the SLT construction language from approved global `SLT__`
references. Its concept determines what is constructed; SLT determines how it is
constructed.

Aion must remain recognizable as its own product identity rather than a variant
of the SLT glyph. Its product-specific geometry and symbolism must not influence
other SLT products unless the user explicitly requests that relationship.

## Visual character

Aion combines:

- a dark field;
- dominant pale structure;
- gold as the signature accent;
- teal as a secondary accent;
- clear structural separation;
- quiet, durable, contemporary geometry.

Within the product interface, the editor is the darkest surface and the sidebar
is raised above it. Gold carries focus, navigation, and the strongest identity
signal. Teal carries a smaller secondary role.

## Approved Aion references

Use these only for Aion work:

- `AION__logo.png` — primary product glyph reference;
- `AION__wordmark.png` — product typography reference;
- `AION__lockup-horizontal.png` — wide composition and presentation reference;
- `AION__lockup-vertical.png` — square or vertical composition reference.

The repository originals currently use lowercase filenames. The normalized
`AION__` names are the filenames to use inside the SLT Visual Studio plugin.

## Generation guidance

For new Aion assets:

1. Use approved global SLT references for construction language.
2. Use approved Aion references for product character and continuity.
3. Preserve existing Aion geometry when refining an approved asset.
4. Prefer one sparse structural concept over several visual metaphors.
5. Keep generated raster work provisional until it is approved and rebuilt as
   editable vector geometry.
